# Protein Inverse Folding Hackathon

## Overview
This repository contains resources for an internal laboratory hackathon focused on testing a **protein inverse folding model**. The goal is to explore and validate the performance of the model in predicting amino acid sequences from given protein structures.

## Purpose of the Hackathon
The hackathon aims to:
- Evaluate the accuracy and efficiency of the inverse folding model.
- Identify potential improvements and new use cases for protein design.
